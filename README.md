# California Housing Data Science Project

## Overview
This project focuses on **Data Preprocessing**, **Log 2 Normalization**, and **Exploratory Data Analysis (EDA)** using the California Housing dataset.

## Tasks Performed
- **Data Cleaning**: Handled missing values and removed duplicates.
- **Normalization**: Applied Log 2 transformation to handle skewed data.
- **Visualization**: Created Histograms, Boxplots, and Scatter plots using Seaborn and Matplotlib.
- **EDA**: Identified that `Median Income` is the strongest predictor of house prices.

## Tools Used
- Python (Pandas, NumPy)
- Matplotlib & Seaborn
- Scikit-learn
